# Workout PDF Coaching Sections V1

Workout v3 PDFs keep exercise tables limited to Exercise, Sets, Reps, Rest, and Notes.

The following content appears after the workout schedule in separate sections:

1. Coach Notes by Day
2. Progression
3. Recovery
4. Safety Guidance

Coach Notes by Day displays every generated exercise cue and effort instruction outside the exercise tables. Progression includes starting load, rep progression, load progression, too-hard response, pain response, and the four-week repeat instruction. Recovery and safety render every validated guidance item.

The renderer no longer creates an empty legacy Safety Notes table for workout v3 plans.

Run validation with:

```bash
npm run validate:workout-pdf-content
```

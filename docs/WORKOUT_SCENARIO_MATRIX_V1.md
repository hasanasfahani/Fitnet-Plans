# Workout Scenario Matrix V1

Phase 10 validates complete generated workout plans for every schedule from two through six training days.

The representative matrix covers:

- Weight loss at 3 days / 30 minutes and 4 days / 45 minutes
- Muscle gain at 5 days / 60 minutes
- Strength at 6 days / 75 minutes
- Home, Building Gym, and Full Equipment Gym
- Neck, shoulder, knee, and lower-back limitations
- Full Body and selected focus areas

Each case validates backend strategy and split, candidate eligibility, selected exercise IDs, place and injury compatibility, session duration, cardio maximums, quality score, progression, recovery, safety, and exercise-level coaching.

Run the matrix with:

```bash
npm run validate:workout-scenarios
```

# Workout Variety Policy V1

Fitnet balances consistency with useful variety.

- A resistance exercise appears once weekly by default.
- A second use requires a specific reason tied to limited approved alternatives, technique practice, progression consistency, equipment, setup, or tolerance.
- Empty, short, or generic duplicate reasons are rejected.
- Same-day duplicate exercise IDs are rejected.
- A third weekly use is rejected when an approved unused alternative exists.
- Cardio may repeat across the maximum two approved cardio sessions with a specific consistency reason.
- Different exercises sharing a useful movement family remain allowed.
- Variety never overrides injury, equipment, role, or candidate safety constraints.

Run validation with:

```bash
npm run validate:workout-variety
```
